# Denga Citizen Services Prototype

A standalone, click-through prototype for a Zimbabwe citizen-services portal. It presents property rates, water, electricity and vehicle licensing in one interface, with simulated EcoCash, OneMoney and card payment flows.

## Open the prototype

Download the repository and open `index.html` in a browser. The interface uses embedded CSS and JavaScript. Google Fonts are optional external resources.

Balances, bills, activity, queue-time savings and payments are demonstration values. The source contains no backend service calls or payment-provider integration.

## Project files

- `index.html` — the complete existing single-file prototype.
- `PUBLICATION.md` — source recovery and publication notes.
- `FILE-MANIFEST.json` — file checksums.

This prototype is separate from the [Denga insurance platform](https://github.com/pmoj1/denga-insurance-platform).
